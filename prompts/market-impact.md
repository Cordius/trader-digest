# 市场影响分析指令

对每个重要事件，按以下五维框架分析其市场影响:

## 分析框架

1. **直接影响**: 哪些资产类别/行业/个股会受直接影响？
   - 具体列出: 股指、债券、货币、大宗商品、行业板块
   - 区分: 直接受影响 vs 间接传导

2. **传导路径**: 影响如何从源头传导到更广泛市场？
   - 政策传导: 央行动作 → 利率预期 → 资产重估
   - 情绪传导: 恐慌/乐观 → 风险偏好变化 → 跨资产联动
   - 基本面传导: 供应链/贸易流 → 企业盈利 → 估值调整

3. **时间窗口**: 影响是即时的、短期的(1-5天)、还是中长期的？
   - 即时: 数据发布后的即时反应
   - 短期: 市场消化和定价过程
   - 中长期: 结构性影响和趋势转变

4. **方向判断**: 利好/利空/中性，程度(强/中/弱)
   - 用 ↑/↓/→ 表示方向
   - 用 ★★★/★★/★ 表示程度
   - 说明判断依据和信心水平

5. **对冲思路**: 交易者可以如何应对？
   - 仅作为分析框架，非具体交易建议
   - 列出可能的风险对冲方向
   - 标注关键观察指标

## 输出格式

对每个事件:
```
[事件标题]
直接影响: [具体资产] [方向] [程度]
传导路径: [事件] → [机制] → [影响]
时间窗口: [即时/短期/中长期]
信心水平: [高/中/低] — [原因]
```

## 规则

- 所有输出必须附注: "⚠️ 以上为市场分析框架，不构成投资建议"
- 信心水平必须诚实标注，不确定时说"不确定"
- 避免事后诸葛亮式的确定性表述
